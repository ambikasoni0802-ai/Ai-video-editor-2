# AI Video Editor (Free, Open Source)

Video upload karo, kisi bhi bhasha mein instruction do, edited video milega.
Website bhi 12 languages mein use kar sakte ho (upar dropdown se).

---

## Files (4 hain)

`app.py`, `requirements.txt`, `Dockerfile`, `README.md`

## Update karne ka process (purani service mein)

1. GitHub par purani `app.py`, `requirements.txt`, `Dockerfile` delete karo
2. Nayi teeno upload karo (ek saath, ek commit)
3. Upload karne se pehle apne Downloads folder mein purani copies
   (app.py, app (1).py, etc.) delete kar do
4. Render "Manual Deploy" dabao
5. 15-20 minute wait karo
