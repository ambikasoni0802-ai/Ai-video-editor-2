# 🎬 AI Video Editor — CapCut-Inspired Version (Free, Open Source)

CapCut ke popular features research karke, jo bhi **free/open-source
tarike se ho sakta tha** wo add kiya hai. Koi paid API nahi.

---

## 📁 Files (4 hain)

`app.py`, `requirements.txt`, `Dockerfile`, `README.md`

---

## 🚀 Update karne ka process (purani service mein)

1. GitHub par purani `app.py`, `requirements.txt`, `Dockerfile` **delete** karo
2. Yeh nayi teeno **upload** karo (ek saath, ek commit)
3. Render "Manual Deploy" dabao (ya apne aap ho jayega)
4. **15-20 minute wait karo**

---

## 🆕 Is baar naya kya add hua (CapCut se inspire, free tarike se)

| CapCut Feature | Humara Free Version |
|---|---|
| Auto captions | ✅ Whisper AI se subtitles (pehle se tha) |
| Green screen | ✅ Chroma key removal (pehle se tha) |
| AutoCut (silence hatana) | ✅ Silence removal (pehle se tha) |
| Speed/Reverse | ✅ **Reverse video** (naya) |
| Split screen | ✅ **2 videos side-by-side** (naya - dusri video upload karni hogi) |
| Background music | ✅ **Music mix karna** (naya - audio file upload karni hogi) |
| Text-to-speech/Voiceover | ✅ **Text ko awaz mein badalna** (naya) |
| Filters/Color grading | ✅ Cinematic/warm/cool/teal-orange (pehle se tha) |
| Templates | ❌ Nahi - templates ek design/UI feature hai, alag se banana padega |
| AI Video Generator (text se naya video) | ❌ Nahi - bahut heavy AI model chahiye, free mein practically possible nahi |
| Voice cloning | ❌ Nahi - yeh heavy AI hai aur privacy/misuse concerns bhi hain |
| Upscaling (4K) | ❌ Nahi - free server (Render) mein itna powerful compute nahi hai |

## 🎛️ Naye features kaise use karo

### Split Screen:
1. Pehli video upload karo (normal box mein)
2. Dusri video **"Extra file"** box mein upload karo
3. Likho: **"split screen karo"**

### Background Music:
1. Video upload karo
2. Music/audio file **"Extra file"** box mein upload karo
3. Likho: **"background music add karo"**

### Text-to-Speech (Voiceover):
1. Video upload karo
2. Likho: **"text to speech karo: Namaste, yeh mera video hai"**
   (jo bolna hai wo quotes ya colon ke baad likho)

### Reverse:
Likho: **"video ulta karo"** ya **"reverse karo"**
